# Mystic Arts Mod

A spiritual successor to The Monk Mod for Minecraft 1.20.1+Fabric

## Features

- **Mystic Codex**: A mystical book that displays your progression level and achievements
- **Ascetic Path (Levels 1–20)**: Traditional monk progression system  
- **Transcendent Path (Levels 21–100)**: Secret levels unlocked through special milestones
- **Combat Scaling**: Unarmed attacks gain power as you progress, with damage and armor scaling
- **Milestones System**: Achieve special accomplishments to unlock new levels

## How to Use

1. Craft the Mystic Codex from books and paper (recipe in game)
2. Open the codex by right-clicking it to view your progression level and achievements
3. Progress through different levels via combat and challenges
4. Unlock Transcendent Path by achieving special milestones like defeating the Ender Dragon

## Development

This mod is built for Fabric 1.20.1 using Java 17.

To build:
```
./gradlew build
```

The resulting jar file will be in `build/libs/`.
